# PPChat multi-IA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O chat passa a responder por um modelo gratuito por padrão (Gemini Flash → Flash-Lite → OpenRouter), mantém o Claude do dono como "Claude (teste)" e aceita a chave do aluno para GPT, Gemini ou Groq.

**Architecture:** `ChatSession` deixa de falar com a Anthropic direto e recebe um `ChatProvider` (Anthropic, ou um adaptador único compatível com OpenAI para OpenAI/Gemini/Groq/OpenRouter). Um registro de opções resolve `modelo` + `chave` numa cadeia ordenada de provedores; a reserva só troca de provedor antes do primeiro token. Um cache em memória guarda respostas do gratuito para perguntas sem SUAP e sem histórico.

**Tech Stack:** Python 3.13, FastAPI, SDK `anthropic`, SDK `openai` (novo), pytest + pytest-asyncio (novos, só dev), front em JS puro.

**Spec:** `docs/superpowers/specs/2026-11-27-multi-ia-design.md`

## Global Constraints

- Opções (ids exatos): `gratis` (padrão), `claude-teste`, `openai`, `gemini`, `groq`. Não existe chave do aluno para Claude.
- Limites por hora: `gratis` 30 por IP / 400 total; `claude-teste` 10 por IP / 100 total; chave do aluno 60 por IP, sem total. Contadores separados por opção. Respostas vindas do cache não contam.
- Reserva do gratuito: Gemini Flash → Gemini Flash-Lite → OpenRouter grátis, **só antes do primeiro token** (429, 5xx ou timeout ao abrir). Falha depois do primeiro token termina a resposta com erro.
- Gratuito esgotado, texto exato: "O modelo gratuito atingiu o limite de uso agora. Tente mais tarde ou use sua própria chave." Nunca cai no Claude do dono.
- Chave do aluno: usada só na requisição; nunca em log, mensagem de erro, cache ou disco. Erros do provedor nunca são repassados como texto bruto.
- SUAP no gratuito: sem `consentimento_gratis: true` na requisição, o servidor descarta o `perfil` para `gratis`.
- Requisição sem `modelo` = `gratis` (clientes antigos).
- Commits sem trailer de co-autoria.

## Review Focus

1. Chave do aluno aparecendo numa mensagem de erro (exceções do SDK costumam ecoar cabeçalhos/URL) → mensagem fixa por tipo de erro, nunca `str(error)`. Teste na Task 3.
2. Cache servindo uma resposta personalizada → não pode haver hit com `perfil`, `history` ou `disciplinas`. Teste na Task 4.
3. Cota caindo no meio da resposta → não reenviar ao próximo provedor (duplicaria texto). Teste na Task 3.
4. `modelo` desconhecido ou opção do aluno sem `chave` → 400 com mensagem clara, sem chamar provedor. Teste na Task 5.
5. Trocar de IA no meio de uma conversa salva → o histórico é texto puro e vale para qualquer provedor. Teste na Task 1.
